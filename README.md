# 🌱 EcoDrop-AI

### AI-Powered E-Waste Collection & Tracking Platform

EcoDrop-AI is an **AI-powered e-waste management platform** designed to make electronic waste collection, classification, reporting, and monitoring more efficient and transparent.

The platform connects **citizens, e-waste collection centers, and government/municipal officials** through a centralized digital system.

## 🚀 Live Application

**Live Demo:** https://ecodrop-ai.netlify.app/

---

## 🎯 Problem Statement

Improper disposal of electronic waste can lead to environmental pollution, health risks, and inefficient recycling.

EcoDrop-AI addresses these challenges by providing a digital platform where users can:

* Locate nearby e-waste drop-off centers
* Identify and classify e-waste using AI
* Report e-waste-related complaints
* Track collection activities
* Help authorities monitor e-waste management
* Improve transparency between citizens and collection authorities

---

## 💡 Key Features

### 🤖 AI-Based E-Waste Classification

Users can use the AI-powered classification system to identify different types of electronic waste.

### 📍 QR-Enabled Drop-Off Centers

Citizens can locate nearby collection centers and use QR-enabled facilities for easier e-waste submission and tracking.

### ♻️ E-Waste Collection Tracking

The platform helps track the movement and collection of e-waste from collection points.

### 📝 Complaint Management

Citizens can submit complaints related to improper disposal, collection issues, or e-waste management.

### 📊 Real-Time Dashboard

Government/municipal officials can monitor collection activities and view relevant information through a centralized dashboard.

### 🔐 User & Admin Management

The application provides separate functionality for users and authorized administrators.

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

### 2. Navigate to the project

```bash
cd EcoDrop-AI
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL provided by your development server.
